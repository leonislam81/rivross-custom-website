# RIVROSS Final WordPress + Elementor Development Blueprint

## 1. Final Website Direction

RIVROSS website হবে **WordPress + Elementor based corporate multi-business website**।

কিন্তু তিনটি business-এর structure একরকম হবে না:

- **Real Estate** → full dynamic section with multiple pages
- **Travel & Tourism** → single standalone landing page
- **Tea Business** → single standalone landing page
- **Corporate pages** → standard Elementor pages
- **Projects / Properties / News / Leadership** → dynamic content যেখানে দরকার

---

# 2. Final Technology Stack

## Theme

**Hello Elementor**

কারণ:
- Lightweight
- Elementor friendly
- Unnecessary theme styling নেই
- Full design control পাওয়া যায়

## Page Builder

**Elementor Pro**

আমাদের দরকার হবে:

- Theme Builder
- Header/Footer
- Dynamic templates
- Loop Grid
- Forms
- Popup
- Custom CSS
- Archive templates
- Single post templates

## Main Plugins

### Required

1. Elementor Pro
2. Advanced Custom Fields
3. Custom Post Type UI
4. Rank Math SEO
5. WP Mail SMTP

### Recommended

6. Fluent Forms — complex inquiry form প্রয়োজন হলে  
7. LiteSpeed Cache — server LiteSpeed হলে  
8. UpdraftPlus — backups  
9. Wordfence — security প্রয়োজন অনুযায়ী  
10. ShortPixel / Imagify / similar image optimizer

### এখন দরকার নেই

- WooCommerce
- JetEngine
- Multiple Elementor addon packs
- Booking engine
- Hotel booking API
- Flight booking API
- Tea eCommerce system

# 43. Performance Rules

Elementor website heavy হয়ে যাওয়ার major reason avoid করতে হবে।

### Do

- Container-based Elementor layout
- WebP/AVIF
- Lazy loading
- CDN
- Cache
- Optimized fonts
- Limited animations
- Minimal plugins

### Don't

- 10 Elementor addons
- Huge videos everywhere
- 5MB images
- Multiple sliders
- unnecessary motion effects

# Final Development Principle

RIVROSS website-টা আমরা **mockup-to-Elementor copy project** হিসেবে build করব না।

Mockup ব্যবহার করব:
